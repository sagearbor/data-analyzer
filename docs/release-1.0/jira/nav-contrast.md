On the page's top bar, the label of the selected tab (for example "Analyze") is almost unreadable: dark text on a dark background. Seen on the live site and on the release build, so it is not new in this release.

# Acceptance criteria
1. The selected tab's label meets the WCAG 2.1 AA contrast level (4.5 to 1) in light and dark mode.
2. Checked in a real browser on the deployed site.

Raised during release 1.0 work (epic ADP-48). Posted by Claude Code for Sage Arbor.
