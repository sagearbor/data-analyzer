Prepare the SDLC release documents for Data Analyzer 1.0 in Confluence, under SDLC / Data Analyzer in the ADP space.

# Acceptance criteria
1. Each document is a copy of the current DS-S-001 template (tables and signature blocks intact), filled in place.
2. Signature and approval fields are left empty. "TBD" marks anything a person must supply.
3. Risk level and solution type are stated as assumptions for a person to confirm.
4. The documents point to the Jira issues, the test results and the code version they describe.
